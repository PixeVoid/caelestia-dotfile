# Ankit's Caelestia Dotfiles

## Fresh Install Steps
1. Install Arch Linux
2. Install Caelestia: `git clone https://github.com/caelestia-dots/caelestia && cd caelestia && fish install.fish --aur-helper=yay --spotify --vscode=code --discord`
3. Restore dotfiles: `git clone https://github.com/PixeVoid/caelestia-dotfile && cd caelestia-dotfile && bash restore.sh`
4. Install apps: `bash apps.sh`

## What's included
- Hyprland config + keybinds
- Caelestia custom overrides (clipse, polkit)
- Fish shell config
- Clipse clipboard theme
- Keybind cheatsheet script (Super+/)
